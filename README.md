# Ascend

اپ شخصی مدیریت زندگی و گلو‌آپ. کاملاً آفلاین، بدون مجوز اینترنت،
داده فقط روی خود گوشی.

> **برای ایجنت‌ها:** قبل از هر تغییری [`AGENTS.md`](AGENTS.md) را کامل بخوان.
> قواعدی در آن هست که نقض‌شان باگ می‌سازد.

---

## نصب سریع

فایل [`release/Ascend.apk`](release/Ascend.apk) را دانلود و روی گوشی باز کن.
اندروید هشدار «منابع ناشناس» می‌دهد — برای هر اپ خارج از گوگل‌پلی عادی است.

اندروید ۸ به بالا. حدود ۲ مگابایت.

## چه می‌کند

**تایم‌لاین تطبیقی** — برنامهٔ دقیقه‌به‌دقیقه که با مدرسه، تمرین فوتبال،
تعطیلات تقویم جلالی و رویدادهای ناگهانی بازنویسی می‌شود.

**حالت‌های واقعیت** — مریضی، روز خراب، سفر، بحران امتحان، رمضان.
برنامه سبک می‌شود و استریک نمی‌شکند. چون زندگی واقعی همیشه ایده‌آل نیست.

**سیستم درسی پایهٔ نهم** — برنامهٔ هفتگی بر پایهٔ ضریب×سختی، معدل وزنی،
توصیهٔ رشته بر اساس نمرات واقعی، دفتر اشتباهات با تحلیل علت.

**گلو‌آپ** — پوست، مو، استایل، منحنی قد، عکس پیشرفت ماهانه،
۴۶ راهنمای تصویری با گام‌های دقیق.

**انضباط** — نقشهٔ وسوسه که ساعت خطر و محرک غالبت را پیدا می‌کند و
راه‌حل مهندسی می‌دهد، نه نصیحت.

**سنجش** — تست‌های بدنی دوره‌ای، بدهی خواب، نقشهٔ فعالیت سالانه،
درخت مهارت با ۲۶ گره، فصل‌های ۱۲ هفته‌ای.

## ساختار

```
engine/          موتور وب — کل منطق و رابط
  *.js           ماژول‌های منطق (تست‌پذیر، بدون DOM)
  src/           لایهٔ رابط (shell، ویوها، تعامل)
  test.js        ۳۷ تست
  lint.js        بررسی ایستا
  build.sh       ساخت HTML تک‌فایلی

app/             پوستهٔ اندروید
  src/main/java/ WebView + اعلان + ویجت (بدون منطق)
  src/main/assets/  خروجی موتور + ۴۶ تصویر

release/         APK آمادهٔ نصب
.github/         CI: لینت → تست → بیلد
```

---

## توسعه

```bash
cd engine
node lint.js     # بررسی ایستا
node test.js     # ۳۷ تست
bash build.sh    # نسخهٔ وب → ASCEND.html
bash build.sh apk  # asset اندروید
bash sync.sh     # هر چهار کار با هم
```

خروجی `ASCEND.html` را مستقیم در مرورگر باز کن — همه‌چیز کار می‌کند
جز اعلان و ویجت که نیتیو هستند.

## بیلد APK

با GitHub Actions. تب **Actions** → **Build APK** → **Run workflow**.

اول لینت و تست اجرا می‌شوند؛ اگر بشکنند APK ساخته نمی‌شود.

برای امضای پایدار این Secrets را تنظیم کن:

| Secret | توضیح |
|---|---|
| `KEYSTORE_B64` | فایل keystore به base64 |
| `KEYSTORE_PASSWORD` | رمز keystore |
| `KEY_ALIAS` | نام کلید |
| `KEY_PASSWORD` | رمز کلید |

ساخت کلید (یک بار، و برای همیشه نگهش دار):

```bash
keytool -genkeypair -v -keystore ascend.jks -keyalg RSA \
        -keysize 2048 -validity 10000 -alias ascend
base64 -w0 ascend.jks    # این را در KEYSTORE_B64 بگذار
```

بدون Secrets هم بیلد می‌شود، ولی با کلید دیباگ که بین بیلدها فرق می‌کند.

## تصمیم‌های فنی

**چرا WebView؟** موتور ۱۸۰+ صفحه منطق تست‌شده دارد. بازنویسی در Compose
ماه‌ها طول می‌کشد و اول کار باگ می‌آورد. لایهٔ نیتیو بعداً تکه‌تکه
جایگزین می‌شود.

**چرا بدون androidx؟** اپ فقط WebView است و به آن کتابخانه‌ها نیاز ندارد.
حذفشان APK را سبک‌تر و منابع را از ۴۸۱KB به ۹۸KB رساند.

**چرا بدون مجوز اینترنت؟** در مانیفست عمداً نیست. حتی اگر جایی اشتباهی
درخواست شبکه بزند، خود اندروید جلویش را می‌گیرد.

**چرا `ascend.local` و نه `file://`؟** با `file://` مرورگر `localStorage`
را محدود می‌کند و ذخیره‌سازی می‌شکند.
