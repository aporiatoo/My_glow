# موتور وب Ascend

اپ تک‌فایلی. همه‌چیز آفلاین، بدون هیچ منبع خارجی.

## دستورها

```bash
bash build.sh        # نسخهٔ وب — تصاویر درون‌خط، تک‌فایلی
bash build.sh apk    # نسخهٔ اندروید — تصاویر از assets/ig، سه برابر سبک‌تر
node lint.js         # بررسی ایستا
node test.js         # ۲۸ تست
bash sync.sh         # لینت + بیلد + تست + همگام‌سازی با apk/engine
```

## قواعد

**تاریخ:** همیشه `td()` یا `dstr()` — هرگز `toISOString()`. بین نیمه‌شب تا
۰۳:۳۰ تهران، UTC روز قبل است و ثبت روی روز اشتباه می‌افتد.

**توابع `window.`:** با پیشوند صدا بزن. `fn()` برهنه در مرورگر کار می‌کند
ولی در تست Node می‌شکند. `lint.js` این را می‌گیرد.

**state جدید:** به `SCHEMA` در `schema.js` اضافه کن، نه به `repair()`.
اگر ساختار قدیمی ناسازگار شد، `SCHEMA_VERSION` را بالا ببر و مهاجرت بنویس.

**تغییر `plan()`:** اگر ورودی تازه‌ای اثر می‌گذارد، به `planKey()` اضافه‌اش کن
وگرنه کش نتیجهٔ کهنه می‌دهد.

**دیالوگ:** فقط `ask()`. هرگز `alert`/`confirm`/`prompt`.

## تست

`test.js` با ۲۸ بررسی: رندر همهٔ ویوها در چهار سناریوی ذخیره، ۷۰ ترکیب
روز×حالت×رمضان برای تداخل زمانی، یکپارچگی محتوا، صحت تاریخ محلی، و قوانین
کاربر (کدو و بادمجان، پروتئین ۱۱۰g).

در CI هر دو قبل از بیلد APK اجرا می‌شوند؛ اگر بشکنند APK ساخته نمی‌شود.
